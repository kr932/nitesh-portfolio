# Nitesh Sai Krishna — Portfolio Website

A colorful, responsive portfolio website created from the details in your resume.

## Run it in VS Code (beginner-friendly)

**This version does not require Node.js.**

1. Download and unzip the portfolio folder.
2. Open Visual Studio Code.
3. Click **File → Open Folder**.
4. Select the unzipped folder named `nitesh_portfolio`.
5. In the left Explorer panel, click `index.html`.
6. Right-click inside the file and choose **Open with Live Server** if you have the Live Server extension.
   - If you do not have Live Server, open the folder in File Explorer and double-click `index.html` to open it in your browser.
7. When you edit a file, save it. With Live Server, the browser refreshes automatically.

## Files

- `index.html` — page content and sections
- `style.css` — colors, layout, typography, and mobile responsiveness
- `script.js` — mobile menu and current year

## Personalize it

Open `index.html` and update:
- Email address
- Phone number if you want it shown (currently omitted from the page for privacy)
- LinkedIn and GitHub links
- Project descriptions and repository/demo links

The portfolio uses information from the resume provided. Some project items are described as concepts/practice work in the resume, so the website avoids claiming that live deployments or public demos exist.

## Before publishing

- Check every link and email address.
- Add GitHub repository links or demos only when they are available and ready to share.
- Do not publish private contact information unless you want it public.
- The Google Fonts import needs an internet connection; the page still works without it using fallback fonts.
